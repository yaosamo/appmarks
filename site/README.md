# Appmarks site

The one-page website, served by Vercel with this folder as the project root.

- **Demo video:** add a screen recording as `site/demo.mp4` (H.264, 16:10, muted, under ~20 MB). The page shows it automatically and falls back to a sketch while it is missing.
- **Icon:** `site/icon.svg` is a placeholder; replace it with the real app icon.
